## 测试包含的故障场景

纯 ID、作品链接、旧链接、标注文本、去重、溢出数字、用户/小说/非 Pixiv 链接、带编号的链接与数字后缀；未收藏新增、同模式跳过、两向取消后重新收藏、原标签保留、取消核验、添加失败恢复、恢复失败停止、元数据读取失败不删除、取消后状态不符、写入成功但响应丢失、作品之间停止；转义/字符串包裹的登录页面数据、缺身份、缺收藏标签、JSON/表单请求格式、HTTP 401/403/404/429/503、非 JSON 响应、匿名或账号改变后的“未收藏”状态。

独立代码复核发现的两处问题均已先补回归测试、观察失败，再修正并跑完整套测试：

1. 链接前后的行号/数字误当成额外作品 ID。
2. 取消请求认证失败后，匿名作品详情中的 `bookmarkData:null` 误记为取消成功。

第二项修正后，认证错误直接停止并报告结果未确认；读取到“未收藏”时另外核验同一账号的登录身份，不能只靠公开作品详情判断。
